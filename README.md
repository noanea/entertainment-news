# つぎいつ？

**Version 1.1** — アニメの次話・配信開始、漫画の次巻、ゲームの発売日を、日付順の予定一覧で見られる静的サイトです。月間カレンダーにも切り替えられます。日付には「公式発表」「予想」「未発表」を付け、出典へ直接リンクします。記事本文・作品画像は転載しません。カードには独自のジャンル装飾を表示します。

初期データは2026年10月1日に確認した公式発表を中心に登録しています。作品・機種・配信先を横断して網羅した一覧ではなく、公式に確認できた予定を掲載する初期版です。

## 公開方法

1. このフォルダを公開GitHubリポジトリのルートに置きます（Pagesサイトとソースコードは誰でも閲覧できます）。
2. GitHub の **Settings → Pages → Build and deployment → Source** で **GitHub Actions** を選びます。
3. `main` ブランチへ変更を push すると Pages が更新されます。初回は **Actions** から `Deploy release calendar` を手動実行できます。
4. PagesのURLを共有できます。URLを知っている人だけに制限する機能ではありません。

## 予定の更新

`data/schedule.json` がカレンダーの掲載データです。現状は、公式発表の正確さを保つため、タイトルごとの予定を確認して編集します。RSS見出しから発売日を自動で決めると誤掲載しやすいため、見出しだけで日付を推定しません。変更後に `updatedAt` を更新してください。

各項目にはジャンル `kind`、作品名 `series`、予定 `title`、日付 `date`（YYYY-MM-DD。年や月までの発表・未発表は `null`）、表示用 `dateLabel`、状態 `status`（`confirmed` / `estimate` / `pending`）、絞り込み `filters`、根拠 `basis`、出典名 `source` と URL を設定します。予測を登録する場合は、予測の根拠と確度が分かる説明を `detail` と `basis` に記載します。根拠を示せない予想日は登録せず未発表のままにします。

旧来のRSS収集用ファイルは公開対象から除外しています。AI APIを使わないため、サイトの表示・公開にAIトークン料金は発生しません。カレンダーは公式発表を確認して `schedule.json` を更新し、公開します。

## ローカル表示

Python 3.11 以上で、このフォルダ内から実行します。

```sh
python -m http.server 8000
```

ブラウザで `http://localhost:8000` を開きます。外部ライブラリ、APIキーは不要です。

## 掲載方針

- 公式サイト、出版社、プラットフォームなどの公開情報へのリンクを案内します。
- 日付や配信先が確認できない場合は「未発表」と表示します。
- 記事本文、画像、ロゴ、スクリーンショット、漫画コマは転載しません。
- 配信先・機種・レーベルで絞り込みます。ジャンル分類は作品・公式情報で確認して設定します。
- `data/schedule.json` は公開データです。個人情報や API キーを入れないでください。
