# つぎいつ？

**Ver.1.50.0** — アニメ・漫画・ゲームの予定を、公式情報へのリンクと一緒に日付順で確認できる静的サイトです。月間カレンダーにも切り替えられます。

## 機能

- アニメ、漫画、ゲームを配信サービス・出版社・機種で絞り込み
- 初期表示は今日以降の予定。選択月、今週、来週、7日、30日、90日、全期間にも切替可能
- 登録済み予定を検索候補から探す。全角・半角をそろえて検索し、全期間が対象
- 条件を含むURLを共有。スマートフォンでは共有メニュー、PCではリンクコピーを利用
- お気に入りを端末内に保存し、JSONファイルでバックアップ・置き換え復元・追加復元
- 日付確定済みの予定をカレンダー用 `.ics` ファイルに保存
- 発表状態（公式発表・予想・未発表）を絞り込み、日付までの残り日数を表示し、今週・来週へワンタップで切替
- テーマカラーを選択し、設定バックアップに含めて移行
- ホーム画面に追加でき、初回表示後はオフラインでも予定表を開ける

## データと公開

`data/schedule.json` が予定データです。データ更新日が1週間以上前になると画面に表示します。公式発表が確認できない日付は補わず、未発表として登録します。各予定には公式サイトや出版社などの確認先を付け、記事本文・作品画像は転載しません。

GitHub Pagesで公開できます。Pagesは公開リポジトリの内容を閲覧できるため、個人情報やAPIキーは登録しないでください。ページはHTML/CSS/JavaScriptとJSONだけで動き、ユーザーの検索・お気に入りは端末内に保存します。

## 更新

予定は出典の公式ページで確認してから `data/schedule.json` を更新します。GitHub Actionsは `main` への変更後にPagesを再公開します。AI APIキーは使用しません。

## ローカル表示

Python 3がある環境でリポジトリ直下から次を実行し、`http://localhost:8000` を開きます。

```sh
python -m http.server 8000
```

## 掲載方針

- 出典は作品公式、出版社、ゲーム会社、配信サービスなどの公式ページを優先します。
- 日付や配信先が確認できない場合は「未発表」と表示します。
- 記事本文、画像、ロゴ、スクリーンショット、漫画コマは転載しません。
- `data/schedule.json` は公開データです。個人情報や秘密情報を入れないでください。
